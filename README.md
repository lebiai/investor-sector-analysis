# 🤖 投资人赛道分析

> 别一个人拍脑袋了——让红杉、Benchmark、软银、高瓴、巴菲特、3G Capital 一起帮你看赛道。

## 这是什么？

一个 AI 投资分析助手。你告诉它一个赛道名称，它会：

**① 先做功课**
从市场、产业链、竞争格局、商业模式、风险、关键成功要素六个维度做客观分析，不带立场。

**② 再请六位"虚拟合伙人"独立发言**
每个机构按照自己的投资哲学、经典框架和风格盲点，对这个赛道独立输出判断——看多、看空、还是不表态。

**③ 找出共识和分歧**
自动识别：
- 大家都同意什么（共识）
- 吵不拢的点在哪（分歧）——是致命分歧还是策略分歧？
- 所有人都忽略了什么（盲点）

**④ 给你四样东西**
- 一份完整的分析报告
- 六家机构的打分对比表
- 一张赛道评分卡（加权打分 + 分歧离散度）
- 一个可以追问的入口

**⑤ 越用越聪明**
每次分析的结果都会记住。下次分析新赛道时，它会跟你之前看过的赛道做对比，帮你发现跨赛道的模式和信号。

## 谁适合用？

- VC/PE 的分析师、投资经理、合伙人
- 产业基金、企业战略投资部门
- 独立投资人、家族办公室
- 任何需要快速理解一个行业赛道的人

## 一句话使用方式

> **"帮我分析一下 [赛道名] 赛道"**

比如：
- "帮我分析一下 AI 机器人赛道"
- "帮我分析一下合成生物学赛道"
- "帮我分析一下工商业储能赛道"

## 看完报告后你可以追问

- "红杉为什么在这个赛道上打 8 分？——看看它的推理链"
- "巴菲特和软银的分歧到底在哪？——展开分歧对比"
- "如果市场增速放缓到 10%，谁的判断还站得住？——压力测试"
- "帮我追加分析政策监管的影响——增加分析维度"

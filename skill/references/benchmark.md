# Benchmark 人设

## 核心信条
"复购率和用户粘性是唯一的真相"

## 核心关注维度
1. **单位经济模型** — CAC vs LTV，是否为正
2. **复购率 / NDR** — 用户究竟多需要这个产品
3. **用户生命周期价值** — LTV/CAC > 3 是基准
4. **增长效率** — 烧钱换增长还是有机增长

## 典型框架
- 漏斗分析（Acquisition → Activation → Retention → Revenue → Referral）
- 单位经济测算模板
- 增长效率 = 净新ARR / 净烧钱

## 投资风格
- 极度数据导向，"show me the numbers"
- 对宏大叙事持怀疑态度，要求每个增长假设有数据支撑
- 冷酷务实，不看"如果"，只看"实际"
- 倾向于少而精的 portfolio，高参与度

## 代表案例
- eBay、Uber（平台经济的单位经济专家）
- Nextdoor、New Relic（高粘性场景）
- Snapchat（早期不赚钱但粘性极高）

## 常见偏见/盲点
- 可能错过需要长周期验证的商业模式（如生物科技、深科技）
- 对增长初期的"负单位经济"容忍度低，可能过早否定潜在赢家
- 对无法量化的壁垒（如文化、品牌认知）重视不足

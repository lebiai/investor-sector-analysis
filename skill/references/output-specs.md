# 输出规范 - Output Specifications

## 用途
本文件定义了四件套输出格式的精确要求。Codex 在执行 Phase 4 输出生成时加载本文件。

---

## Output 1: 完整分析报告

一份可阅读的 Markdown 文档，结构如下：

```markdown
# [赛道名称] — 多机构投资分析报告

## 执行摘要
（1 段话概括核心发现）

## 市场分析
[通用分析正文]
> 🔍 **辩论注解：**[争议点] — [分歧机构]

## 产业链分析
[同上结构]

## 竞争格局分析
[同上结构]

## 商业模式分析
[同上结构]

## 风险分析
[同上结构]

## 关键成功要素
[同上结构]

## 机构观点摘要
### 红杉 — [立场]（置信度：[高/中/低]）
### Benchmark — [立场]（置信度：[高/中/低]）
### ...

## 共识、分歧与盲点
（从辩论引擎结果复制）
```

**辩论注解格式：**
> 🔍 **辩论注解：**[争议点] — [哪些机构参与分歧]

## Output 2: 机构辩论对比表

一个 10 行 × 9 列的表格，使用如下标准维度：

```markdown
| 维度 | Sequoia | Benchmark | SoftBank | Hillhouse | Buffett | 3G Capital | 平均分 | 分歧级别 |
|------|---------|-----------|----------|-----------|---------|-----------|-------|---------|
| 市场规模 | N | N | N | N | N | N | N.n | ⚡⚡/⚡/🔵 |
| 竞争壁垒 |  |  |  |  |  |  |  |  |
| 单位经济 |  |  |  |  |  |  |  |  |
| 商业模式可持续性 |  |  |  |  |  |  |  |  |
| 技术成熟度 |  |  |  |  |  |  |  |  |
| 估值合理性 |  |  |  |  |  |  |  |  |
| 团队/管理层 |  |  |  |  |  |  |  |  |
| 退出确定性 |  |  |  |  |  |  |  |  |
| 风险回报比 |  |  |  |  |  |  |  |  |
| **综合得分** |  |  |  |  |  |  |  |  |
```

每个单元格：1-10 分。分数指代：1-3=很差 4-5=低于平均 6-7=良好 8-9=优秀 10=极为罕见。
分歧级别：标准差 ≥2.5 = ⚡⚡ Fatal，1.5-2.5 = ⚡ Strategic，<1.5 = 🔵 Cognitive。

```markdown

| 评估项目 | 得分 | 权重 | 加权分 |
|---------|------|------|-------|
| 市场规模与增长 | N/10 | 25% | X.XX |

| 单位经济与盈利性 | N/10 | 20% | X.XX |

| 风险回报比 | N/10 | 10% | X.XX |
| **综合加权得分** | **X.XX/10** | **100%** | **X.XX** |

**分歧离散度（标准差）：**
- 市场规模：X.X（低/中/高分歧）
- ...

**总体结论：** CONSENSUS BUY / CONSENSUS PASS / CONTROVERSIAL

**阵营分析：**
| 阵营 | 机构 | 立场 |
|------|------|------|
| 🟢 看多 | [机构] | [一句话] |
```

## Output 4: 可追问状态

分析报告正文结束后，必须输出以下追问引导：

---

**分析完成。你可以进一步追问：**

1. **追问某个机构的推理** — 例如："红杉为什么在市场维度打8分？"
2. **追问某个分歧** — 例如："巴菲特和软银在护城河上的分歧具体在哪？"
3. **压力测试** — 例如："如果市场增速放缓到10%，谁的判断还站得住？"
4. **追加分析维度** — 例如："帮我分析一下政策监管对这个赛道的影响"
5. **深入盲点** — 例如："展开讲讲[某个盲点]对投资的影响"
6. **参考历史案例** — 例如："这个赛道和之前分析的[某赛道]有什么异同？"
